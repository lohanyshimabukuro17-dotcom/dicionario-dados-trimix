# Dicionário de Dados — Trimix Sorveteria

Documentação interativa do banco de dados `trimix_sorveteria`, preparada para a atividade de Governança de Dados do Grupo 07 (UNICID).

Acesse o site via GitHub Pages após habilitar **Settings → Pages → Deploy from a branch → main / (root)**.

Os arquivos `index.html`, `style.css` e `script.js` formam o site; `docs/` contém a especificação e o DDL, e `assets/der.png` contém o diagrama.
