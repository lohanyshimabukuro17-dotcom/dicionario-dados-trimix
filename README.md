# Dicionário de Dados — Trimix Sorveteria

Projeto acadêmico da UNICID — Grupo 07. Documentação estática de **19 tabelas e 113 colunas** extraídas do DDL recebido.

## Recursos
Busca instantânea, modo claro/escuro, modal DER com Panzoom, download da especificação e tags indicativas de LGPD/GDPR e RBAC.

## Publicação
Publique **o conteúdo desta pasta na raiz do repositório** e configure Settings → Pages → Deploy from a branch → main → /(root).

## Pendências técnicas
- O arquivo DOC6 não foi fornecido. Papéis de Data Owner/Data Steward precisam ser confirmados pela equipe.
- O PDF contém o documento v1.1 preservado e um anexo de revisão proposta v1.2; correções no modelo Workbench e DDL ainda precisam ser aplicadas e testadas.
- O DER exibido é a exportação recebida, não um DER comprovadamente corrigido.
- Panzoom depende de acesso à CDN.
- Classificações LGPD/GDPR e RBAC são documentais, não implementação de permissões.
